# Code of Conduct

YASLA aims to be a welcoming project for people with different backgrounds,
experience levels and accessibility needs.

Treat people with respect. Critique code and design decisions with evidence and
clear suggestions. Make room for newcomers, acknowledge mistakes and respect
people's privacy and boundaries.

Harassment, discrimination, threats, sexualized conduct, personal attacks and
publishing private information without permission are not acceptable.

Maintainers may edit or remove harmful content, limit participation or exclude
participants when necessary. They should apply responses proportionately and
handle reports confidentially where possible.

The public conduct-reporting contact has not yet been configured. Before publication,
the maintainer must provide a private reporting channel. Until then, use an existing
private contact with the maintainer rather than posting personal details publicly.
